# Paper notes

This folder keeps the paper-level evidence used during the review.

- The historical P0–P3 candidate set contains 403 records and is preserved as the original note layer.
- `papers/` now contains 404 normalized notes: the 403 historical records plus revision-stage scope addition Record 760.
- `original_sources/` now contains the matching 404 paper-specific synthesis-source files.

The final qualitative synthesis contains 386 studies. Of these, 385 come from the reconciled historical candidate set and one (Record 760) was added during reviewer-driven scope re-adjudication from the already-existing publication-eligible pool. The decision is documented in `data/reviewer_scope_readjudication.csv`.

The notes are evidence records, so their paper-specific content has been preserved rather than stylistically rewritten during repository cleanup.
