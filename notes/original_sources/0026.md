# PaLM-E: An Embodied Multimodal Language Model

## Paper-specific synthesis

### Contribution and architecture

Driess et al. introduce **PaLM-E**, an embodied multimodal language model that injects continuous observations—images, robot state estimates and other sensor representations—into the embedding space of a pretrained decoder-only language model. Rather than translating all perception into text before reasoning, learned encoders produce vectors with the same dimensionality as language-token embeddings, allowing sensor observations and text to be interleaved in one autoregressive context.

The model is trained jointly on robotics tasks and large vision-language/language datasets. The largest configuration, **PaLM-E-562B**, combines a PaLM-540B language backbone with a large vision encoder and is trained as one generalist checkpoint.

### Tasks and findings

The evaluation includes **three robotic environments**, two involving real robots, together with VQA, image captioning and language tasks. In robotics, PaLM-E emits high-level textual plans that are executed by low-level policies. The paper demonstrates long-horizon mobile manipulation, replanning after changes in the environment, generalization to objects not previously encountered by a particular robot, and task-and-motion-planning scenarios.

Joint training produces **positive transfer** across embodiments and task domains: adding diverse vision-language data improves embodied tasks instead of forcing a separate specialist model. Scaling also reduces catastrophic loss of the underlying language abilities.

On general visual-language evaluation, the single PaLM-E-562B checkpoint reports **66.1% accuracy on OK-VQA**, then the highest reported result in the paper's comparison, without task-specific OK-VQA fine-tuning.

### Relevance to generalized Web agents

PaLM-E is strong foundational evidence for a multimodal agent design principle: heterogeneous sensor observations can be injected directly into an LLM's context and jointly reasoned over with language. A Web analogue is an agent that consumes screenshots or other interface state alongside instructions and action history.

The paper also shows why perception and action should be separated carefully: PaLM-E produces plans, while a distinct low-level policy translates language plans into robot actions. Similarly, browser agents need a reliable grounding/execution layer between semantic plans and actual clicks or DOM operations.

### Limitations

The robotics stack relies on separate low-level policies and controlled robot environments; successful high-level planning is therefore not equivalent to robust end-to-end actuation. The 562B model is extremely large, making compute and deployment cost significant. The work is not a Web benchmark and does not address HTML/DOM structure, browser state changes, schema validation, extraction provenance or adversarial webpages.

### Evidence locations

Architecture and multimodal input representation: model section. Robotics/multi-embodiment setup and transfer: embodied-task experiments. General VLM comparison including OK-VQA: Table 5 / visual-language evaluation. Qualitative replanning/generalization and discussion: robotics analysis and conclusion.

### One-sentence synthesis

PaLM-E demonstrates that a single large language model can directly reason over interleaved continuous sensor and language representations across multiple embodiments, providing a useful multimodal-agent architecture precedent while leaving the Web-specific grounding and execution problem unsolved.
