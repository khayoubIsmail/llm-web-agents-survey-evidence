## Simple understanding

SelfCheckGPT is a method for detecting hallucinations in black-box LLMs. It samples multiple responses from the model and checks whether statements are consistent across samples.

The intuition is simple: if the model knows something, different samples should agree. If the model is hallucinating, samples may contradict each other.

For the thesis, this paper is useful because web agents need verification. A web agent that hallucinates page content, extracted facts, or action outcomes can fail seriously.

## Notes

- **Core idea:**
  Detect hallucination by measuring consistency across multiple sampled model outputs.

- **Key contribution:**
  Provides a zero-resource, black-box hallucination detection approach that does not require model probabilities or external databases.

- **Key finding:**
  SelfCheckGPT performs well for sentence-level hallucination detection and passage-level factuality ranking.

- **Thesis limitation:**
  It detects inconsistency in generated text, but it does not verify against a live web page or external evidence.

- **Connection to web automation:**
  Consistency checking can inspire verification modules for extracted data, generated summaries, and agent decisions.

- **Use in thesis:**
  Use it to discuss hallucination detection and self-consistency-based verification.

## Thesis-ready paragraph

Manakul et al. proposed SelfCheckGPT, a black-box hallucination detection method based on consistency across multiple sampled outputs. The method assumes that factual knowledge tends to produce consistent generations, while hallucinated statements are more likely to diverge or contradict across samples. For LLM-based web agents, this idea is relevant because hallucination can lead to incorrect extraction, false page-state assumptions, or unsafe actions. However, SelfCheckGPT does not ground outputs in the actual web environment, so web agents still require browser-state verification, retrieved evidence, and execution feedback.

## Why this paper matters for my thesis

This paper matters because it gives a practical verification idea that can be adapted to agent settings: sample, compare, and detect inconsistency.
