# A Survey of Frontiers in LLM Reasoning: Inference Scaling, Learning to Reason, and Agentic Systems

## Paper-specific synthesis

### Scope and taxonomy

This survey organizes recent LLM reasoning research along two orthogonal axes. The first is **learning regime**—especially inference-time scaling versus learning/training to reason. The second is **architecture**—standalone LLMs, single-agent systems and multi-agent systems. This structure is broader than a catalogue of prompting methods because it connects how reasoning is acquired with where reasoning happens in an agent architecture.

The inference-scaling part covers sampling/search, verification, self-refinement and tool-supported computation. The learning-to-reason part covers reasoning-data construction and collection, supervised/process training, rejection sampling, reinforcement learning and preference-based optimization. The agentic part discusses planning, memory, retrieval, external tools, action coordination and multi-agent collaboration.

### Findings relevant to agent design

The survey emphasizes that inference-time methods can improve reasoning without changing model parameters but pay for this flexibility with additional computation and with gains that can saturate. Tool use is presented as a way to overcome internal limitations by outsourcing exact computation or accessing changing external information. Multi-agent systems can diversify reasoning and distribute roles, but coordination, communication and verification become separate failure points.

For learning-to-reason, the paper distinguishes improving the quality/coverage of reasoning trajectories from improving the optimization objective. It notes limitations of common preference methods such as DPO, including length biases and degradation under prolonged training, and reviews process-supervision approaches intended to make reasoning signals more informative than outcome-only labels.

### Relevance to generalized Web agents

The taxonomy maps cleanly to Web automation. A Web agent can improve at inference time through search, branching, reflection and tool calls; it can improve through training on trajectories; and its architecture can range from one LLM controlling the browser to coordinated specialist agents for navigation, extraction and verification. The survey is therefore useful for positioning agent reasoning mechanisms rather than for supplying Web benchmark results.

Its treatment of tools is especially relevant: calculators, compilers, search engines and APIs provide capabilities the base model cannot reliably internalize. In a Web extraction system, the analogous tools include browser automation, DOM/AX inspection, parsers, validators and storage interfaces.

### Limitations for evidence use

This is a secondary survey spanning a fast-changing literature. It synthesizes heterogeneous evaluations rather than running one controlled benchmark across the compared methods, so it should not be used to infer that one reasoning family is quantitatively superior across Web tasks. Many examples concern math/code/general reasoning rather than browser interaction, and multi-agent benefits depend heavily on orchestration overhead and evaluation setting.

### Evidence locations

Overall taxonomy: introductory taxonomy/Figure 3. Inference-time scaling and single-agent reasoning: Section 3. Learning-to-reason/data/optimization: later training sections. Agentic tools and coordination: agent architecture subsections. Limitations of inference computation and preference optimization: discussion within those sections. Applications/open problems: closing sections.

### One-sentence synthesis

The survey frames modern LLM reasoning as the interaction of inference-time computation, learned reasoning behavior and standalone/single-/multi-agent architectures, offering a useful organizing lens for Web-agent reasoning while providing secondary rather than task-specific empirical evidence.
