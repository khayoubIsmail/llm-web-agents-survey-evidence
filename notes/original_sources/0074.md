# The Rise and Potential of Large Language Model Based Agents A Survey

## Research problem and contribution

This survey asks how large language models change the design space for agents and proposes a broad reference architecture organized around a brain, perception, and action. It connects that architecture to single-agent applications, multi-agent collaboration, human-agent interaction, and agent societies, then discusses evaluation, safety, scaling, and open questions. Its value is primarily conceptual synthesis: it treats the LLM as only one part of an agent that must sense, decide, remember, use tools, and affect an environment.

## Scope and analytical framework

The brain component covers reasoning and planning, memory, and the use of general or specialized knowledge. Perception expands beyond textual instructions to visual, auditory, tactile, and other environmental inputs. Action is divided into textual output, tool/API use, and embodied action. The survey uses these components to organize systems across individual assistants, cooperative or competitive multi-agent systems, and human-agent collaboration. A separate agent-society discussion distinguishes individual behavior and personality from environmental design and emergent social phenomena.

The discussion section proposes three evaluation dimensions. Utility concerns whether an agent completes delegated tasks and can be assessed by task success, efficiency, cost, and robustness. Sociability concerns communication, cooperation, role behavior, and interaction with humans or other agents. Values concern honesty, harmlessness, and alignment with social expectations. This multidimensional framing is important because task success alone can reward systems that complete the objective in unsafe, misleading, or socially inappropriate ways.

## Key contributions and implications

The brain–perception–action model remains a useful high-level decomposition for web agents. Browser observations and screenshots belong to perception; planning, memory, reflection, and knowledge retrieval belong to the brain; clicks, form submission, API calls, and generated text belong to action. This separation exposes interface risks: perceptual errors can corrupt plans, memory can preserve stale or malicious content, and apparently correct plans can still become harmful actions.

The survey also treats tools as capability extenders rather than proof of autonomy. It notes that LLM limitations motivate external search, calculation, and APIs, while tool choice and action sequencing remain unresolved. Its sections on adversarial robustness, trustworthiness, privacy, and social impact emphasize that broad action spaces increase both capability and consequence. Scaling the number of agents introduces communication cost, message propagation, coordination, and controllability problems rather than guaranteeing collective intelligence.

## Limitations and critical assessment

This is a narrative survey, not a systematic review. It provides no reproducible database search, date range, inclusion criteria, duplicate screening, or quality-appraisal procedure, so comprehensiveness and selection bias cannot be independently assessed. The architecture is deliberately broad and therefore does not specify operational interfaces, state representations, failure recovery, or security boundaries. Categories overlap—for example, memory is part of the brain but can also be implemented through external tools, while action and perception become intertwined during repeated browser interaction.

The paper ranges from implemented systems to speculative claims about agent societies and AGI. Those claims have different evidence strength and should not be synthesized as if they were comparable empirical results. Many examples predate later web-agent benchmarks and modern prompt-injection work, so the taxonomy is foundational rather than current coverage. The survey also describes evaluation ideals more clearly than validated measurement protocols; sociability and values often depend on subjective or model-based judgments. Quantitative and causal claims should therefore be traced to the cited primary studies.

## Relevance to the survey

Use this paper to define an LLM-based agent as an integrated perception–decision–action system and to motivate evaluation beyond endpoint task success. For the web-agent synthesis, the most defensible use is conceptual: map DOM/screenshot understanding, memory and planning, and browser/tool execution onto distinct components, then analyze failures and safeguards at their interfaces. Do not use the paper as primary evidence that any particular agent capability or social phenomenon has been achieved.
