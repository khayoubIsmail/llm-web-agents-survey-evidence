# ART: Automatic Multi-step Reasoning and Tool-use for Large Language Models

## Paper-specific synthesis

### Method

ART (Automatic Reasoning and Tool-use) represents multi-step reasoning as a generated program. For a new task, it retrieves demonstrations from a library of prior task programs; the frozen LLM generates intermediate steps, and execution pauses when a tool call is emitted so the tool result can be inserted before generation continues. The design removes the requirement to hand-author a complete task-specific chain-of-thought/tool script for every new problem.

### Empirical evidence

The paper evaluates zero-shot transfer on unseen BIG-Bench and MMLU tasks. ART substantially improves over ordinary few-shot prompting and automatic chain-of-thought and matches hand-crafted CoT prompts on a majority of evaluated tasks. In reported aggregate comparisons, ART reaches roughly **54.6 average accuracy on the BIG-Bench test set versus 47.7 for a few-shot baseline**, with especially large gains on arithmetic/algorithmic tasks. A reported MMLU comparison gives approximately **66.45 for ART versus 54.84 for the baseline setup**. Tool ablations show that external execution is a real contributor rather than only the retrieved demonstrations.

The framework is deliberately editable: a human can correct a generated task program or add a tool, and the paper demonstrates large task-specific gains from small interventions.

### Relevance to Web agents

ART is a precursor to agent systems in which an LLM produces an executable action plan while an external runtime performs operations and returns observations. It supports separating semantic reasoning from deterministic tools and reusing successful action patterns across tasks. For Web automation, analogous programs may call search, browser, parser or validation tools.

### Limitations

The task library and available tools strongly constrain what can be transferred. Program retrieval can select irrelevant demonstrations, tool calls can be malformed, and the paper's benchmarks are mostly reasoning tasks rather than dynamic websites. Human editing improves results but weakens claims of fully autonomous generalization.

### Evidence locations

Task-library/program architecture: method. BIG-Bench/MMLU transfer: main experiments. Tool contribution and demonstration-selection analysis: ablations. Human correction/new-tool experiments: extensibility section.

### One-sentence synthesis

ART shows that a frozen LLM can retrieve reusable reasoning programs and interleave generated steps with external tool execution, improving unseen reasoning tasks and motivating programmatic agent runtimes, though its evidence is not from live Web environments.
