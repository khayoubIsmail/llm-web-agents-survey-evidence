API-Bank: A Comprehensive Benchmark for Tool-Augmented LLMs contributes to the literature on **tool-use / api-calling / action space** by showing how LLM-based systems can move beyond isolated text generation toward more agentic behavior. The paper's central value is its focus on: construct an api-use benchmark that tests tool search, tool selection, parameter filling, and multi-turn tool execution.
