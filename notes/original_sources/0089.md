# Chameleon: Plug-and-Play Compositional Reasoning with Large Language Models

## Paper-specific synthesis

### Architecture

Chameleon is a compositional reasoning system in which an LLM planner selects and orders **plug-and-play tools** rather than solving every subproblem internally. Its modules include language models, vision models, Web search, Python functions and task-specific heuristics. The planner generates a program/tool sequence whose intermediate outputs are passed to later modules.

### Results

The system is evaluated on two multimodal knowledge-intensive benchmarks. With GPT-4 as planner, Chameleon reaches **86.54% overall accuracy on ScienceQA**, reported as an **11.37-point improvement** over the best published few-shot result at the time. On TabMWP, GPT-4-powered Chameleon reaches **98.78%**, a **17.0-point improvement** over the prior state of the art in the paper's comparison. The analysis finds the GPT-4 planner more consistent and rational in tool selection than the ChatGPT-based planner, especially when the instruction implies constraints that determine which modules are useful.

### Relevance to Web agents

Chameleon is direct architectural evidence for modular Web agents: a controller can select search, visual perception, code and structured utilities according to the task instead of forcing one monolithic model to perform all functions. This pattern is relevant to browser agents that combine DOM access, screenshots, search, parsers and validators.

### Limitations

Performance depends strongly on the planner and on the curated module inventory. The two main evaluations are QA/table reasoning rather than live browser interaction; tool interfaces are known in advance; and high final-answer accuracy does not test permission handling, irreversible actions or field-level provenance. Planner errors can also select a wrong module even when each tool works correctly.

### Evidence locations

System/module architecture and planner: method. ScienceQA and TabMWP comparisons: main result tables. Planner/tool-selection behavior: analysis/ablation sections. Failure/caveat discussion: qualitative analysis and conclusion.

### One-sentence synthesis

Chameleon shows that an LLM planner can compose heterogeneous specialist modules into high-performing reasoning programs, supporting modular agent design while making planner quality and tool-selection errors explicit bottlenecks.
