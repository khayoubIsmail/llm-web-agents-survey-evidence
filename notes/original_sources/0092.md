# Gorilla: Large Language Model Connected with Massive APIs

## Paper-specific synthesis

### Problem and method

Gorilla addresses large-scale API calling, where an LLM must select and correctly instantiate APIs whose documentation can change. APIBench is built from roughly **1,645 ML APIs** from TorchHub, TensorFlow Hub and Hugging Face. The authors fine-tune a LLaMA-7B-based model and introduce **Retriever-Aware Training**, so API documentation retrieved at test time becomes part of the generation context rather than a static training-time assumption.

### Evaluation and findings

The benchmark distinguishes functional API-call accuracy from **hallucination** using AST-based matching. Gorilla substantially reduces hallucinated API calls compared with directly prompted general LLMs while retaining high API functionality accuracy. In the NeurIPS comparison, Gorilla's zero-shot hallucination rates are about **6.98% / 10.95% / 5.40%** on TorchHub / Hugging Face / TensorFlow Hub, versus **36.55% / 37.16% / 78.65%** for the GPT-4 zero-shot baseline reported in the same table. Corresponding Gorilla functionality accuracies are approximately **59.13% / 71.68% / 83.79%**.

A particularly important experiment changes API documentation at test time. Retrieval-aware conditioning lets Gorilla adapt to updated documents, whereas a model relying on memorized API forms is more brittle.

### Relevance to Web agents

Gorilla is strong evidence for **retrieval-grounded tool selection under changing documentation**. Web-agent toolsets, APIs and site schemas evolve, so retrieving the current interface/documentation at execution time is safer than assuming static parametric knowledge. Separating accuracy from hallucination is also directly useful for evaluating tool-calling Web agents.

### Limitations

APIBench focuses on ML APIs rather than arbitrary Web services or graphical interfaces. Retrieval can itself return the wrong documentation and mislead the model. AST matching checks call structure but not all semantic side effects, authorization constraints or downstream data quality. Good API-call generation therefore does not imply safe end-to-end automation.

### Evidence locations

APIBench construction: dataset section. Retrieval-aware training: method. Accuracy/hallucination comparisons: main result tables. Documentation-change and retriever studies: analysis/ablation sections.

### One-sentence synthesis

Gorilla shows that retrieval-aware training can reduce API hallucination and adapt tool calls to changing documentation at large catalog scale, a directly relevant precedent for dynamic Web-agent tool grounding.
