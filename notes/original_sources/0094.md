# Large Language Models as Tool Makers

## Paper-specific synthesis

### Method

LATM (LLMs As Tool Makers) separates tool creation from tool use. A strong LLM first writes a reusable executable tool for a class of problems, tests/repairs it on demonstrations, and stores it behind an API. Subsequent instances are solved by a cheaper LLM that retrieves and invokes the cached tool. The cache therefore stores **functionality**, not merely past natural-language answers.

### Findings

The paper evaluates complex reasoning tasks including BIG-Bench-style problems. With GPT-4 as the one-time tool maker and GPT-3.5 as the repeated tool user, LATM achieves performance comparable to using GPT-4 throughout while substantially reducing average inference cost once the tool is reused across enough instances. The experiments also show that tool validation/repair matters: generated code that passes the maker's checks can then convert repeated reasoning into deterministic execution.

### Relevance to Web agents

LATM suggests that repeated Web workflows need not be re-planned from scratch. An agent can synthesize a reusable scraper/action/validation function once, verify it, and then invoke that function for later sites or records. This is particularly relevant to skill libraries and cached workflows in generalized automation.

### Limitations

Tool making requires a strong model and trustworthy execution sandbox. A generated tool can encode a wrong assumption that is then reused at scale; cached tools can become stale as interfaces change; and the study uses reasoning benchmarks rather than live websites. Cost benefits depend on sufficient reuse to amortize tool construction.

### Evidence locations

Two-phase LATM framework and validation loop: method. BIG-Bench/task experiments and maker/user model split: results. Cost amortization and cache analysis: efficiency section. Tool-generation failures: analysis/discussion.

### One-sentence synthesis

LATM shows that expensive LLM reasoning can be converted into validated reusable tools and amortized across repeated requests, a useful skill-caching pattern for agents provided stale or incorrect tools are actively revalidated.
