# ExpeL: LLM Agents Are Experiential Learners

## Paper-specific synthesis

### Method

ExpeL learns from agent experience **without changing model weights**. During a training phase the agent executes tasks, stores successful/failed trajectories and uses an LLM to extract reusable natural-language insights by contrasting experiences. At inference it receives both retrieved past trajectories and accumulated insights. This separates concrete episodic recollection from abstract procedural knowledge.

### Results

Experiments span **HotpotQA, ALFWorld and WebShop**. Removing one memory form shows task-dependent effects: abstract insights are particularly useful for HotpotQA, while retrieving concrete trajectories is especially useful in ALFWorld; WebShop benefits from both because it requires reasoning plus precise interaction. The paper reports roughly **36% vs 31%** HotpotQA success for insight-only vs retrieval-only, **50% vs 55%** in ALFWorld, and near-balanced **37% vs 38%** in WebShop for those restricted variants.

ExpeL also transfers learned experience across tasks. On FEVER, Act/ReAct obtain **58/63%**, while transferred ExpeL reaches **70%** with task demonstrations (65% without them). The study compares favorably with Reflexion while avoiding repeated trial attempts during evaluation.

### Relevance to Web agents

WebShop makes ExpeL directly relevant: a generalized agent can accumulate reusable lessons from past sites while separately retrieving similar concrete trajectories. This supports cross-task memory, recovery heuristics and continual improvement without fine-tuning proprietary models.

### Limitations

Experience quality depends on the base agent's exploratory runs and on LLM-generated insight extraction; bad experiences can yield bad rules. Retrieval/insight stores grow and can contain stale knowledge. The benchmark set is small, and improvement from prior task experience does not establish robust generalization to arbitrary sites.

### Evidence locations

Experience/insight architecture: method. Main three-domain results and restricted-memory variants: experiments/figures. Cross-task FEVER transfer and Reflexion comparison: transfer analysis. Limitations: discussion/conclusion.

### One-sentence synthesis

ExpeL demonstrates that agents can improve by storing trajectories and distilling reusable natural-language lessons without parameter updates, with WebShop evidence showing that abstract insights and concrete recollection play complementary roles.
