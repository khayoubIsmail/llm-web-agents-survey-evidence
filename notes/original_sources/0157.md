# ReflAct: World-Grounded Decision Making in LLM Agents via Goal-State Reflection

## Paper-specific synthesis

### Motivation and method

ReflAct targets a specific failure of ReAct-style agents: reasoning can drift away from the agent's **actual environment state and goal**, so later actions are based on an inconsistent internal belief. Instead of reasoning mainly about the next action, ReflAct repeatedly reflects on the relation between current state and desired goal and uses that state-goal representation to guide the next decision.

### Concrete results

Across the paper's interactive agent experiments, ReflAct improves substantially over ReAct. The authors report an **average 27.7% improvement over ReAct** and a **93.3% success rate on ALFWorld**. ReflAct also exceeds ReAct augmented with additional modules such as Reflexion or a World Knowledge Model in the reported comparisons, supporting the authors' claim that improving the core state-grounded reasoning backbone can be more effective than stacking corrective modules on top of a drifting trajectory.

The failure analysis attributes many ReAct errors to inconsistent beliefs, missed state changes and actions that no longer align with the remaining goal conditions. ReflAct's explicit state-goal reflection reduces these compounding errors.

### Relevance to generalized Web agents

This is directly relevant to browser automation because every click, form submission, navigation or filter changes state. An agent that continues reasoning from an outdated page representation can compound errors rapidly. ReflAct supports making **state reconciliation and remaining-goal tracking** explicit before choosing actions, rather than treating the browser trajectory as a flat text history.

### Limitations

Goal-state reflection depends on the LLM correctly interpreting observations; if the observation itself is incomplete or the model misstates the current state, reflection can still be wrong. Extra reflection increases token/latency cost. The benchmarks are controlled interactive environments, so the method does not directly address noisy DOMs, visual grounding, permissions, provenance or adversarial Web content.

### Evidence locations

ReAct failure diagnosis and belief/goal mismatch: introduction/analysis. ReflAct formulation: method. Aggregate gains and ALFWorld 93.3% result: main experiments. Module comparisons and error behavior: ablations/error analysis.

### One-sentence synthesis

ReflAct shows that explicitly reconciling an agent's current world state with its remaining goal can reduce compounding ReAct errors and markedly improve interactive-task success, making state-grounded reflection a strong design principle for Web agents.
