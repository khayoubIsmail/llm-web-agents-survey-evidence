# Knowledge-enhanced Agents for Interactive Text Games

## Research problem and contribution

This paper asks whether explicit domain knowledge can improve functional grounding in interactive text games, where an agent must convert language observations into a sequence of valid actions. It contributes a knowledge-injection framework using two complementary forms of knowledge: commonsense relations and environment/action affordances. The important point for agent research is that an LLM or language encoder does not need to infer every constraint from sparse interaction data if stable domain knowledge can be supplied explicitly.

## Method and evaluation

The injected knowledge is incorporated into learning-based action-selection agents and evaluated in text-game environments, including task settings associated with TextWorld and ScienceWorld. The experiments compare base agents with versions augmented by commonsense and affordance information. Reported gains vary by underlying model and task: the paper records modest improvements in some settings and much larger relative gains in others, including a 48% relative improvement for one affordance-enhanced configuration. This heterogeneity matters more than the single best figure: injected knowledge helps when it aligns with the action constraints, but it is not uniformly beneficial.

## Limitations and critical assessment

The environments are text-only and constrained, so the results do not establish robustness on visually rich, dynamic websites. Knowledge construction and matching can also become a new failure point; incorrect or incomplete affordances may restrict exploration. The evaluation is therefore evidence that structured priors can help grounding, not evidence that knowledge injection alone solves open-world planning.

## Relevance to the survey

Use as supporting evidence for grounding, memory, and action-space design. For web agents, schema or affordance knowledge can reduce invalid actions, but it should remain revisable and be checked against the live interface.
