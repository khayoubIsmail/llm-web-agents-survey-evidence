# AdaRefiner: Refining Decisions of Language Models with Adaptive Feedback

## Research problem and contribution

AdaRefiner targets decision tasks where a frozen general LLM needs environment-specific guidance but full fine-tuning or elaborate prompt engineering is impractical. Its main contribution is a lightweight adapter language model that converts feedback produced during reinforcement learning into revised task understanding and decision guidance for the LLM-agent loop.

## Method and evaluation

The LLM supplies high-level assistance, while an RL agent interacts with the environment and produces performance feedback. The adapter learns to refine the information passed to the decision model, creating an adaptive feedback channel without modifying the large model itself. Evaluation covers 22 tasks in the open-world Crafter environment and includes model/backbone and component ablations. The reported pattern is strongest on higher-level or commonsense-dependent skills, where sparse rewards make unguided RL particularly difficult.

## Limitations and critical assessment

Evidence comes from one game environment and a bounded set of tasks. Success therefore depends on the adapter learning a useful interpretation of reward signals; delayed, noisy, or strategically misleading feedback may not transfer. The separation preserves the base model but introduces another learned component whose errors are harder to attribute. Results should be treated as evidence for adaptive mediation between language guidance and RL, not general cross-environment adaptation.

## Relevance to the survey

The architecture is relevant to agents that learn from execution outcomes. For web agents, a small adaptation layer could translate site-specific failures into revised instructions while leaving the main model fixed, provided feedback is validated and reversible.
