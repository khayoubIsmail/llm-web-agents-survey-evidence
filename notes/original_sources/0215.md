## Analysis

<!-- note-body-start -->
### Research problem and contribution

AgentKit is a graph-based prompting framework in which nodes contain natural-language subtask prompts and edges encode dependencies. Users compose a visible “thought process” that can include hierarchical planning, conditional branches, reflection, and learning from prior interaction.

### Method and evaluation

The runtime evaluates node prompts in dependency order and can attach Python pre/post-processing for databases, control flow, or structured output. The paper instantiates agents for WebShop and Crafter. It reports state-of-the-art results under its comparison, including an 80% relative improvement in one WebShop analysis and a roughly five-point gain over a prior few-shot Crafter agent in the highlighted zero-shot setting. The examples show that a common node abstraction can express several agent capabilities.

### Limitations and critical assessment

The graph is largely hand designed; accessibility shifts, rather than removes, process-engineering work. Every node can add an LLM call, increasing latency and cost, and errors can propagate through dependencies. Reported benchmark gains are tied to particular prompt graphs and model versions, so graph structure should be ablated separately from token budget.

### Relevance to the survey

AgentKit is useful as an explicit orchestration representation. For web agents, graph nodes make planning and verification stages auditable, but the manually encoded workflow may not generalize to new sites.
