# Agent Planning with World Knowledge Model

## Research problem and contribution

The World Knowledge Model (WKM) paper distinguishes prior task knowledge for global planning from dynamic state knowledge for local action selection. A separate parametric model synthesizes and supplies both forms of textual knowledge to an agent model.

## Method and evaluation

Knowledge is self-synthesized from expert and sampled trajectories, then learned with a separate LoRA that shares a backbone with the agent. Tests use ALFWorld, WebShop, and ScienceWorld with Mistral-7B, Gemma-7B, and Llama-3-8B. Against ReAct, Reflexion, NAT, ETO, and KnowAgent, WKM improves each tested backbone across seen and unseen splits; for Mistral-7B the displayed gains range from 1.39 to 5.44 points. Analyses examine unseen-task transfer, weak-WKM/strong-agent combinations, invalid actions, and unified training.

## Limitations and critical assessment

The model cannot know reliably what knowledge the agent lacks, represents the world only as text, does not update dynamically when the environment changes, and adds inference overhead. These stated limitations are central for the web, where state quickly becomes stale. Gains are consistent but often incremental over tuned baselines.

## Relevance to the survey

Use as evidence that global task priors and local state knowledge are distinct planning inputs. A web implementation should retrieve and refresh them separately rather than store both in a static prompt.
