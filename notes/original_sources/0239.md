## Analysis

<!-- note-body-start -->
### Research problem and contribution

TaskBench decomposes tool-based automation into three separately measurable capabilities: task decomposition, tool selection, and parameter prediction. Tool Graphs represent both tools and valid interconnections, while “back-instruction” generates user requests from executable graphs.

### Method and evaluation

Datasets cover Hugging Face tools, multimedia tools, and daily-life APIs and receive human verification after automated construction. TaskEval combines text overlap for subtask descriptions with node, edge, graph, and argument metrics. Tests across proprietary and open LLMs show different strengths by stage and domain. Difficulty rises sharply with graph size: graph accuracy falls from 96.16% for single-node tasks to 39.31% at six tools and 25.00% at eight tools in the reported analysis. Tool parameter prediction is also roughly 20 F1 points harder than node/tool prediction across models.

### Limitations and critical assessment

Synthetic instructions inherit the graph and generator's assumptions, and component metrics may not predict successful live execution. ROUGE rewards wording overlap rather than plan equivalence. Tool availability, side effects, authentication, and changing schemas are largely outside the benchmark.

### Relevance to the survey

TaskBench supports stage-wise diagnosis: a web agent may understand a request yet fail at tool choice or arguments. End-to-end execution should supplement, not replace, these component metrics.
