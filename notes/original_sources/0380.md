### Concrete evidence verified from the full paper

- **Benchmark:** CRAB Benchmark-v0 contains **120 cross-environment desktop/mobile tasks** in the final ACL version.
- **Evaluation:** a graph-based evaluator scores fine-grained progress instead of reducing every task to one terminal bit.
- **Extensibility:** any environment exposing Python-callable actions can be added, enabling cross-device workflows.
- **Result:** the best reported configuration, a single GPT-4o agent, achieves **38.01% completion ratio**.
- **System finding:** multi-agent decomposition is not automatically superior; coordination overhead can offset specialization benefits.

#### Author-stated / evidence-based limitations

The framework abstracts device interaction through configured action APIs and evaluator graphs, so quality depends on task/evaluator authoring. The initial benchmark remains small relative to the diversity of real computer environments.

---

### Limitations

- **Limitation 1:** Results may be environment-specific.
- **Limitation 2:** Office/workplace tasks often require exact state changes that are hard for agents to verify.
- **Limitation 3:** Live or high-fidelity environments increase realism but also evaluation complexity.

General limitation for your thesis:

```text
A benchmark evaluates only a slice of agent behavior.
No single benchmark proves that an agent can perform generalized web automation and data extraction.
```

Therefore, use this paper as a **P2 supporting source**, not as the sole basis for a central claim.
