#### Core idea

Benchmark agents on desktop or workplace workflows involving UI interaction, application state, documents, files, or enterprise tools.

The paper mainly evaluates this capability:

```text

+ factual grounding
+ state changes
+ efficiency/cost
+ safety/reliability
```
