### Concrete evidence verified from the full paper

- **Environment:** Windows Agent Arena provides a real Windows OS with common applications, browser access and unrestricted multi-application workflows.
- **Task set:** **150+ diverse Windows tasks** adapted from the OSWorld evaluation philosophy.
- **Scalable execution:** Azure parallelization reduces a full benchmark run from days to roughly **20 minutes**.
- **Result:** the proposed Navi agent achieves **19.5%**, while unassisted humans achieve **74.5%**.
- **Cross-domain evidence:** Navi is additionally tested on Mind2Web, probing whether computer-use mechanisms transfer to Web interaction.

#### Author-stated / evidence-based limitations

Cloud VM scaling does not remove dependence on Windows/application versions, and 150+ tasks cannot represent all desktop workflows. Human-agent gaps remain large despite efficient evaluation.

### Limitations

- **Limitation 1:** Results may be environment-specific.
- **Limitation 2:** Office/workplace tasks often require exact state changes that are hard for agents to verify.
- **Limitation 3:** Live or high-fidelity environments increase realism but also evaluation complexity.

General limitation for your thesis:

```text
A benchmark evaluates only a slice of agent behavior.
No single benchmark proves that an agent can perform generalized web automation and data extraction.
```
