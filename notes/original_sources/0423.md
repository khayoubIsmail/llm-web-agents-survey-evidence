### Concrete evidence verified from the full paper

- **Benchmark:** AgencyBench evaluates **6 core agentic capabilities across 32 real-world scenarios and 138 tasks**.
- **Long horizon:** a scenario averages roughly **90 tool calls, 1 million tokens and hours of execution time**.
- **Automated interaction:** a user-simulation agent provides iterative feedback while a Docker sandbox evaluates visual and functional deliverables using rubrics.
- **Result:** closed-source systems average **48.4%**, versus **32.1%** for open-source systems.
- **Analysis:** resource efficiency, feedback-driven self-correction and tool-use preferences differ substantially by model and agent scaffold.

#### Author-stated / evidence-based limitations

The simulated user cannot reproduce all human feedback behavior, and Docker/rubric judges approximate rather than duplicate real deployment. Extreme token/tool budgets also make routine replication expensive.
