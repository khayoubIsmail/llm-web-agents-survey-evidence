### Concrete evidence verified from the full paper

SynthAgent automatically adapts web agents using synthetic supervision collected from structured exploration. It groups discovered website states into task categories, generates tasks from those states, removes/refines conflicting or ambiguous goals, and globally refines trajectories before training. Across the paper's web-agent evaluations, this pipeline outperforms alternative synthetic-data generation strategies, showing that quality control at both task and trajectory levels matters as much as raw synthetic-data volume.

#### Author-stated / evidence-based limitations

Synthetic goals can still reflect the generator's biases and may not match real user intent. Conflict detection and trajectory refinement add model-judging stages whose mistakes can propagate into training.
