## Analysis

<!-- note-body-start -->
### Research problem and contribution

This paper defines conversational web navigation: an agent must execute a sequence of user instructions while preserving both dialogue context and evolving browser state. It contributes MT-Mind2Web, constructed from Mind2Web demonstrations, and Self-MAP, a self-reflective memory-augmented planning framework.

### Method and evaluation

Single-turn tasks are modified and linked into multi-turn sessions. Self-MAP compresses earlier user instructions, actions, observations, and rationales into memory snippets, retrieves what is relevant to the current turn, and reflects on the evolving trajectory before planning. Evaluation reports element accuracy, operation F1, step success, and task success across domain/generalization splits, with task success as the main metric. Self-MAP improves over direct full-history, simple summaries, query rewriting, and other memory baselines in the displayed table; performance nevertheless falls as conversations become longer and dependencies more complex.

### Limitations and critical assessment

The dataset composes sessions from existing annotated trajectories, so dialogue and state changes are less open-ended than live users. Summarization can erase constraints, while repeated reflection increases latency. The experiments also reveal a sharp gap between step-level scores and end-to-end task completion, which should be retained rather than hidden by averages.

### Relevance to the survey

This is direct evidence for multi-turn web agents. It supports memory that jointly tracks user commitments and browser effects, with end-to-end task success reported alongside action accuracy.
