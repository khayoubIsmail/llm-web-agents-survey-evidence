### Detailed notes

- Defines three core capabilities for web agents: high-level planning, low-level execution, replanning.
- Extends Mind2Web-Live with human-aligned high-level plans derived from key-node annotations.
- Compares natural-language high-level plans and PDDL-like structured high-level plans.
- PDDL plans improve matched rate and reduce unmatched steps compared with natural-language plans.
- Even with human-authored high-level plans, low-level execution remains weak: execution success is much lower than planning alignment.
- Action-object prediction has a high invalid/hallucinated action rate, while action-ID and expanded action spaces reduce invalid actions but introduce other errors.
- Failure modes include repetitions, hallucinated links, redundant actions, and out-of-domain links.
- Replanning improves task execution, but can reduce alignment to human plans because it creates more executable but less human-aligned adaptations.
- Recommendations: separate planning and execution, improve perceptual grounding, design action spaces that allow uncertainty, and make fine-grained process evaluation standard.

### Thesis relevance

This paper supports the S5.5 thesis claim:

```text
Web-agent failure is multi-layered.
It can arise from benchmark design, perception, action grounding,
planning, execution, recovery, evaluation, robustness, or deployment conditions.
```

For **LLM-based agents for generalized web automation and data extraction**, this matters because extraction agents must not only complete clicks. They must also remain reliable under:

```text
incorrect navigation
incomplete forms
visual/DOM mismatch
long trajectories
network and server failures
malicious or irrelevant content
evaluation ambiguity
```

### Limitation as thesis gap

The thesis-relevant gap is:

```text
diagnosing web-agent failure is improving,
but current systems still do not provide a complete reliability architecture for:
- robust perception
- safe planning
- precise grounding
- recovery from failed actions
- infrastructure-failure handling
- adversarial-page handling
- structured extraction verification
- source provenance
```

Therefore, this paper should be used as evidence that generalized web automation needs a reliability layer, not only stronger models.

### Thesis-ready paragraph

Hierarchical Planning Failures contributes to S5.5 by showing that current web-agent limitations cannot be understood only through aggregate task success. Analyzes web-agent failure through a hierarchical planning framework with three layers: high-level planning, low-level execution, and replanning. The main result is that PDDL high-level plans are more concise and aligned than natural-language plans, but low-level execution remains the dominant bottleneck; one round of replanning improves subgoal and plan completion. For the thesis, this paper is important because generalized web automation and data extraction require reliability at multiple layers: the agent must understand the task, perceive the page, ground actions correctly, recover from failures, preserve evidence, and verify extracted outputs. However, The framework is diagnostic and text/DOM-focused, with limited multimodal analysis; for the thesis, it strongly explains where agents fail but does not solve grounding, safe execution, or extraction verification. Therefore, this work should be used to motivate a failure-aware architecture for web agents.
