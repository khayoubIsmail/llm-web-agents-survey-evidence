---

### Concrete evidence verified from the full paper

WebInject optimizes visually subtle webpage perturbations that survive the nondifferentiable browser rendering pipeline and cause screenshot-based web agents to emit attacker-chosen actions. Across five MLLM-based agents and ten webpage datasets, it substantially outperforms prior webpage/screenshot attacks. For Gemma-3, WebInject reaches 0.972 ASR versus 0.062 for the strongest webpage-based baseline and 0 for screenshot baselines. ASR remains above roughly 0.85 across multiple monitor configurations, and semantically equivalent user prompts retain similar effectiveness.

#### Author-stated / evidence-based limitations

The threat model assumes the attacker can modify target webpage source code. Closed-source MLLM transfer was not evaluated, and the attack requires optimization for a target webpage/action setting.
