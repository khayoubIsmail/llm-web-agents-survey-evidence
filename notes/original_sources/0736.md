## Analysis

<!-- note-body-start -->
### Research problem and contribution

AirGapAgent addresses contextual privacy leakage when a conversational agent has access to a rich personal profile and interacts with a possibly malicious third party. Its threat model is context hijacking: the attacker changes the apparent situation so the agent discloses information unnecessary for the user's actual task. The defense operationalizes contextual integrity through data minimization, logical isolation, and escalation to the user when more information is legitimately needed.

### Method and evaluation

An LLM-based minimizer sees the base task and privacy directive, selects only relevant profile fields, and passes that reduced view to a separate conversational model; the third party cannot directly influence the minimizer. Evaluation uses synthetic profiles, 26 personal-data fields, eight task scenarios, multiple-choice and open-ended questions, and Gemini Ultra/Pro, GPT-4, and Mistral Large. On the easier dataset, a hijacking attack drops Gemini Ultra baseline privacy from 94.4% to 45.2%, whereas AirGapAgent retains 96.7% privacy with 87.3% utility. Across tested models, the defense generally restores high privacy while sacrificing some task utility. The complete evaluation set contains 16,640 examples, with harder fields and broader tasks used to test generality.

### Limitations and critical assessment

The same class of language model helps generate profiles, contextual labels, attacks, and minimization decisions, creating correlated-model and synthetic-data risks. Contextual appropriateness is not validated against real users, cultures, or changing preferences. The design assumes the trusted base context and minimizer are not attacker-controlled; compromised task descriptions, poisoned memory, or leakage through derived attributes fall outside the core experiment. Privacy metrics can also overstate protection when a model guesses sensitive values from auxiliary fields. Finally, the method supplies empirical isolation rather than a formal non-interference guarantee and can omit data needed for task completion.

### Relevance to the survey

AirGapAgent is strong evidence for least-privilege context design in personal web agents. It shows that prompt-level confidentiality can collapse under contextual manipulation and that architectural separation of sensitive memory from untrusted web content is a more meaningful control, albeit one that still requires trustworthy minimization and user-centered policy evaluation.
