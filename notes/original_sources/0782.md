### Concrete evidence verified from the full paper

This study analyzes MCP security across the full server lifecycle—creation, deployment, operation and maintenance—rather than treating MCP as a single tool-call interface. The final taxonomy distinguishes four attacker types and 16 threat scenarios and maps threats to lifecycle activities, trust boundaries and mitigations. The paper also surveys real MCP adoption and integration patterns, then derives secure-by-design recommendations around server provenance, authorization, tool/resource integrity, monitoring and maintenance. For the survey, its main contribution is a lifecycle view showing that MCP risk can originate before invocation and persist through deployment/update channels, not only through prompt injection at run time.

#### Author-stated / evidence-based limitations

This is primarily a landscape/security-analysis paper rather than a controlled attack benchmark, and MCP is evolving rapidly. The taxonomy and case studies cannot guarantee coverage of future protocol revisions, implementation-specific vulnerabilities or every production trust configuration.
