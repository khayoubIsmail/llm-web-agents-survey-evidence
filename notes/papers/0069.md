### Paper 18 — Reflexion: Language Agents with Verbal Reinforcement Learning

#### Paper contribution

Shinn et al. propose **Reflexion**, a language-agent learning framework that converts environmental or self-evaluation feedback into natural-language reflections stored in episodic memory. Unlike gradient-based RL, the policy parameters need not be updated; learning occurs by changing the textual context available to the actor on subsequent trials.

#### Architecture and learning loop

Reflexion separates three roles:

- **Actor:** generates actions/solutions, often using ReAct or CoT.
- **Evaluator:** produces a scalar/binary assessment using environment feedback, heuristics, LLM self-evaluation, or generated tests.
- **Self-Reflection model:** converts the trajectory and evaluation into a concise verbal lesson stored in long-term memory.

The actor conditions on both short-term trajectory history and long-term reflections. In ALFWorld the memory is truncated to the **last three reflections** to avoid context overflow; in programming the maximum memory is one experience. This makes the memory mechanism explicit and auditable rather than treating the base LLM context as unlimited memory.

#### Evaluation domains

The paper tests three distinct capabilities:

1. sequential decision-making in **134 ALFWorld environments** across six task types;
2. reasoning/search QA on **HotPotQA**;
3. code generation/debugging on **HumanEval, MBPP, and LeetcodeHardGym**, including Python and Rust settings.

LeetcodeHardGym contains **40 hard LeetCode problems in 19 programming languages**.

#### Concrete results

- **ALFWorld:** ReAct + Reflexion solves **130/134 tasks** with the heuristic self-evaluator. The paper reports an absolute **22% improvement** over the strong baseline across iterative trials.
- **HotPotQA:** the paper reports roughly **20% absolute improvement** over the compared reasoning baseline in its Reflexion setup.
- **HumanEval Python:** Reflexion achieves **91.0% pass@1**, compared with GPT-4 at 80.1% and the cited prior CodeT+GPT-3.5 result at 65.8%.
- **HumanEval Rust:** GPT-4 baseline 60.0% vs **68.0% Reflexion**.
- **MBPP Rust:** GPT-4 baseline 70.9% vs **75.4% Reflexion**.
- **Leetcode Hard Python:** GPT-4 baseline 7.5% vs **15.0% Reflexion**.
- A negative result matters: on **MBPP Python**, Reflexion is 77.1% versus the GPT-4 baseline at 80.1%, showing that reflection can be harmed by unreliable self-generated tests.

#### Error and ablation evidence

The code-generation analysis identifies the evaluator as a critical bottleneck. On MBPP Python, internally generated tests have a **16.3% false-positive rate**, versus about **1.4% on HumanEval Python**, explaining why Reflexion can prematurely accept wrong code.

On the 50 hardest HumanEval-Rust problems:

- baseline GPT-4: 60%;
- self-reflection without test generation: **52%**;
- test generation without self-reflection: **60%**;
- full Reflexion: **68%**.

This ablation shows that neither verbal reflection nor tests alone provide the reported improvement; useful external evaluation and reflection must cooperate.

#### Failure modes and limitations

- The method depends heavily on the **quality of feedback/evaluation**. A faulty self-evaluator can reinforce an incorrect lesson.
- Verbal policy optimization can converge to **non-optimal local minima**, explicitly stated in the limitations.
- Long-term memory is implemented as a small sliding window in this study rather than a scalable persistent memory system.
- For programming, test-driven evaluation is difficult for nondeterministic, API-dependent, hardware-dependent, parallel, or concurrent functions.
- Reflection is not guaranteed to identify the true causal error; it is an LLM-generated interpretation of feedback.
- Repeated trials increase latency/cost and may be unsafe when actions are irreversible in real environments.

#### Relevance to generalized web automation and extraction

Reflexion is strong P0 evidence for **error recovery and experience memory**. A web agent can compress a failed trajectory into a lesson and reuse it after navigation, extraction, or validation failures. But the paper's evaluator analysis is equally important for the survey: an agent should not learn from a self-generated success signal unless the signal is externally verifiable. For schema-guided extraction, deterministic validators and provenance checks are better feedback sources than ungrounded self-judgment.

#### Synthesis statement

Reflexion demonstrates that language agents can improve across trials by storing verbalized lessons rather than updating model weights—solving 130/134 ALFWorld tasks and reaching 91% HumanEval pass@1—but the method succeeds only when evaluation is trustworthy; noisy self-generated tests can reverse the gain, making externally grounded feedback essential for web-agent recovery.
