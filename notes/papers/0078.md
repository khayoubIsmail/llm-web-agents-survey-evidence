### Paper-specific synthesis

#### Core method

Self-Refine is a training-free test-time loop in which the same LLM acts as **generator, feedback provider and refiner**. It first produces an answer, critiques that answer with task-specific feedback, and regenerates conditioned on both the previous answer and critique. The loop can repeat until a stopping condition is met. No supervised fine-tuning or reinforcement learning is required.

#### Evaluation and results

The paper evaluates **7 diverse tasks**, including review/sentiment rewriting, acronym generation, story/common-generation, code optimization/readability, dialogue response generation, constrained generation and mathematical reasoning, using GPT-3.5/ChatGPT/GPT-4-class models. Across the suite, Self-Refine improves the same base model by roughly **20 percentage points absolute on average**, with individual gains ranging from about 5 points to more than 40 depending on task/metric. Human preference and automatic metrics generally agree that iterative outputs are better than one-shot outputs.

Iteration analyses show that useful gains can continue over more than one feedback/refinement cycle, but improvement is not guaranteed indefinitely; the process can plateau or propagate a mistaken critique.

#### Relevance to Web agents

Self-Refine is evidence for a lightweight **reflection/recovery loop** in agents. A Web agent can critique an unsuccessful extraction, invalid schema instance or failed action and revise the next attempt without retraining. This is most defensible as evidence for test-time self-correction, not as proof that self-reflection can verify factual correctness.

#### Limitations

The method assumes the same model can recognize defects in its own output. Incorrect feedback can reinforce the original mistake; refinement adds tokens/latency; and several tasks have subjective evaluation criteria. The paper does not use a browser environment or external state verifier, so success on generation tasks does not establish reliable recovery from real Web-side effects.

#### Evidence locations

Framework/algorithm: method section. Seven-task design and model setup: experiments. Aggregate and per-task gains: main results tables. Iteration behavior/component analyses: analysis/ablation sections. Failure examples and caveats: qualitative analysis/discussion.

#### One-sentence synthesis

Self-Refine shows that an LLM can often improve its own first-pass output through iterative natural-language critique and revision without training, supporting reflection loops in agents while leaving the reliability of self-generated feedback as a central limitation.
