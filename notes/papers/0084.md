### Paper-specific synthesis

#### Method

ViperGPT separates visual reasoning from perception by asking a code-generation LLM to write **Python programs** against a predefined visual API. The generated program can call modules for image localization, cropping, classification, captioning or language operations and then combine their outputs with ordinary Python control/data manipulation. No additional end-to-end training is required for the program generator.

#### Evidence

The paper evaluates complex visual reasoning across multiple benchmarks, including visual question answering and referring/spatial reasoning, and reports state-of-the-art or competitive results despite using off-the-shelf modules. The important empirical result is architectural rather than a single score: explicit executable composition generalizes across task families and makes the intermediate computation inspectable. The ICCV study also presents generated programs and failure cases showing that errors can originate either in program synthesis or in a called perception module.

#### Relevance to Web agents

This is a strong precedent for **code-as-action** agents. A Web agent can similarly translate a natural-language goal into executable calls to browser/query/extraction primitives rather than emitting every low-level action directly. The generated program provides a trace that can be inspected, retried or validated.

#### Limitations

ViperGPT inherits errors from its vision modules and from code generation. The API is curated and much cleaner than a changing website; generated Python can fail syntactically or semantically; and the experiments do not test browser state, permissions, side effects or schema-constrained extraction.

#### Evidence locations

Architecture/API and Python execution: method section. Cross-benchmark comparisons: experiments/result tables. Generated programs and module/program failures: qualitative/error-analysis sections.

#### One-sentence synthesis

ViperGPT shows that an LLM can solve diverse visual tasks by generating executable Python that composes specialist perception modules, supporting programmatic agent architectures while exposing separate program-generation and tool-level failure modes.
