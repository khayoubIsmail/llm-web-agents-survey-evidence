Gorilla: Large Language Model Connected with Massive APIs contributes to the literature on **tool-use / api-calling / action space** by showing how LLM-based systems can move beyond isolated text generation toward more agentic behavior. The paper's central value is its focus on: improve llm api calling by grounding generation in retrieved api documentation.
