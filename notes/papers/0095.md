### Paper-specific synthesis

#### Architecture

MemoryBank adds three persistent components around an LLM: **memory storage**, semantic **memory retrieval**, and **memory updating**. Memories are assigned strength and can decay over time using an Ebbinghaus-forgetting-curve-inspired rule; repeated/important memories are reinforced. The system also synthesizes higher-level descriptions of the user's personality from interaction history.

The paper instantiates the design in SiliconFriend and tests it with ChatGPT, ChatGLM and BELLE variants, including additional psychological-dialog tuning for the companion use case.

#### Evaluation

The quantitative simulation uses **15 synthetic users over 10 days** and **194 probing questions** about prior interactions, alongside qualitative real-user dialogues. The MemoryBank-enabled systems improve recall of relevant prior information and the coherence/correctness of responses compared with variants that lack the persistent memory mechanism. Reported ChatGPT-based results include strong retrieval/response metrics; the central finding is that persistent retrieved memory preserves information across sessions that would otherwise fall outside the model's active context.

#### Relevance to Web agents

MemoryBank is useful evidence for separating **long-term agent state from the context window**. A Web agent can store site/task experiences, retrieve only relevant prior trajectories, reinforce reusable knowledge and allow stale details to decay. This can reduce repeated exploration and context growth.

#### Limitations

Forgetting strength is heuristic rather than learned from downstream task utility. Retrieved memories can be wrong or outdated and may bias future decisions. The evaluation targets conversational companionship rather than objective action success, and storing user history raises privacy/governance concerns absent from most benchmark settings.

#### Evidence locations

Memory architecture/updating rule: method. SiliconFriend and data setup: application/evaluation sections. 10-day simulated-user evaluation and qualitative studies: experiments. Caveats: discussion/conclusion.

#### One-sentence synthesis

MemoryBank demonstrates that explicit persistent storage, retrieval and controlled forgetting can extend LLM interaction beyond the context window, motivating long-term agent memory while highlighting staleness, privacy and retrieval-quality risks.
