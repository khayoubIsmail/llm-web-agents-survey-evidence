### Paper-specific synthesis

#### Architecture

MetaGPT turns software-development **standard operating procedures (SOPs)** into a structured multi-agent workflow. Specialized roles—such as product manager, architect, project manager and engineer—produce explicit intermediate artifacts (requirements, design, task lists, code) rather than relying on free-form group chat. A shared environment routes messages/artifacts between roles, and executable feedback is used to detect implementation errors.

#### Results

On code-generation benchmarks, the paper reports **85.9% pass@1 on HumanEval** and **87.7% on MBPP**. On the authors' SoftwareDev benchmark of 70 development tasks, MetaGPT produces more executable/coherent projects than chat-style multi-agent baselines; reported executability is around **3.75/4.0 versus 2.25 for ChatDev**. Ablations show that role specialization/SOP structure and executable feedback both contribute to the gains rather than the result being simply “more agents.”

#### Relevance to Web agents

MetaGPT is evidence for **role-specialized orchestration with typed intermediate artifacts**. A Web-extraction system can analogously separate navigation, extraction, validation and provenance roles while communicating through explicit schemas instead of unconstrained dialogue. SOP-like workflows are also useful for repeatable recovery and auditing.

#### Limitations

Multi-agent decomposition consumes more tokens and latency than a single pass. Errors in upstream artifacts can cascade despite verification. The software-engineering setting has executable tests that provide unusually strong feedback; many Web tasks lack such deterministic oracles. More agents therefore do not automatically imply better reliability.

SOP/role architecture: framework section. HumanEval/MBPP and SoftwareDev: experiments. Executable-feedback/role ablations: analysis section. Cost and cascading-error discussion: limitations/conclusion.

#### One-sentence synthesis

MetaGPT shows that encoding human SOPs into specialized LLM roles with explicit artifacts and executable feedback can improve complex software collaboration, motivating structured multi-agent Web workflows while retaining coordination and cascading-error costs.
