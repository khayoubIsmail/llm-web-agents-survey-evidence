### Paper-specific synthesis

#### Method

CodeAct replaces constrained JSON/text tool-call syntax with **executable Python code as the unified action language**. The agent can compose several tool calls, manipulate intermediate values, write control flow and inspect execution feedback inside one action. This makes the action representation both expressive and directly executable.

The paper evaluates **17 LLMs** under code-action and conventional text/JSON-action prompting, then constructs approximately **7K CodeActInstruct trajectories** to fine-tune CodeActAgent models.

#### Concrete evidence

Across the evaluated API/tool-use and embodied settings, executable code actions improve agent success by **up to about 20 percentage points** relative to less expressive action formats. One reported GPT-4-1106 comparison reaches **74.4% average success with CodeAct**, versus roughly **53.7%** for the corresponding JSON/text-action formulation. Fine-tuning on CodeActInstruct further improves open-source model behavior and transfers to tasks not seen in the instruction data.

The trajectory analyses show why code helps: several dependent operations can be combined, intermediate values can be transformed locally, and execution errors become explicit observations that support repair.

#### Relevance to Web agents

For Web extraction, code actions can express operations such as iterating through records, transforming text, validating schema fields, deduplicating outputs and composing API/browser calls without forcing an LLM turn between each primitive. This is especially useful when the task mixes deterministic computation with environment interaction.

#### Limitations

Giving an agent executable code increases the attack and safety surface. Sandboxing, resource limits and permission controls become essential. Code generation can fail syntactically or invoke tools incorrectly, and benchmark environments expose clearer APIs than arbitrary websites. Higher expressivity therefore trades action brevity for stronger execution-governance requirements.

#### Evidence locations

Action-space definition: method. Seventeen-model comparison and tool/embodied tasks: main experiments. CodeActInstruct and fine-tuned agents: training section. Action-format/component analyses and limitations: later experiments/discussion.

#### One-sentence synthesis

CodeAct shows that executable Python provides a more expressive and effective agent action space than constrained text or JSON calls, improving multi-step tool use while making sandboxing and execution safety first-class requirements.
