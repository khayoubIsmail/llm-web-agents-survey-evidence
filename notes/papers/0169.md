### Paper-specific synthesis

#### Scope and formalization

Lei et al. define an LLM agent as a system using an LLM as the core reasoning engine to perceive an environment, choose actions and pursue goals. The paper formalizes the agent through a tuple covering the model, environment, state space, action space and policy, then surveys more than **100 papers spanning 2020–2024**.

#### Four-part taxonomy

The survey organizes the literature into four complementary architectural categories:

1. **Reasoning-enhanced agents** — chain-, tree- and graph-structured deliberation and action-coupled reasoning.
2. **Tool-augmented agents** — external APIs, code, retrieval and knowledge resources.
3. **Multi-agent systems** — communication and collaborative problem solving among LLM instances.
4. **Memory-augmented agents** — mechanisms for persistent or retrieved context beyond a single prompt.

It then compares applications in software engineering, scientific research, embodied robotics and **Web automation**, using benchmarks such as SWE-bench, WebArena and AgentBench to illustrate capability gaps.

#### Main synthesis

The review argues that impressive structured-task performance has not removed the main deployment bottlenecks: long-horizon planning remains brittle, hallucination can propagate into actions, memory/tool modules increase system complexity, and safety becomes more consequential once agents can alter external state. It identifies neuro-symbolic integration, multimodal perception and human-agent collaboration among promising directions.

#### Relevance to generalized Web agents

The taxonomy is useful for positioning reasoning, tools, multi-agent orchestration and memory as composable Web-agent capabilities. The paper is especially relevant as a secondary cross-domain synthesis showing that Web automation shares architectural patterns with software and embodied agents.

#### Limitations and publication caution

The full version verified in this audit is explicitly marked **“not peer-reviewed”** by Preprints.org and was posted on 24 December 2025. Therefore it should not be described as a peer-reviewed archival source unless a later publication is independently confirmed. Its benchmark discussion is secondary and cannot replace primary WebArena/SWE-bench/AgentBench papers for numeric claims.
