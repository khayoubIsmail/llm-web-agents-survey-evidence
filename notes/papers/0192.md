## Analysis

<!-- note-body-start -->
### Research problem and contribution

Lemur and Lemur-Chat are open models designed to balance natural-language competence with code generation, on the premise that capable agents need both communication/planning and executable interaction. The contribution is a code-intensive pretraining and instruction-tuning recipe for a general agent backbone, not a new agent loop.

### Method and evaluation

The models are built by continuing training with a mixture emphasizing code and then instruction tuning on both text and code tasks. Evaluation includes conventional language and programming benchmarks plus agent-oriented settings: IC-CTF, WebArena, ALFWorld, and MINT tasks with or without GPT-4 feedback. Lemur-70B-Chat improves over Llama-2-70B-Chat and CodeLlama-34B-Instruct across the reported balance of text/code tasks and narrows, but does not close, the gap to GPT-4. On the displayed WebArena comparison it scores 5.30 versus GPT-4's 10.59, while outperforming the listed open baselines.

### Limitations and critical assessment

The model is large and costly, and several agent results remain low in absolute terms. Results combine base-model quality with prompting, environment interfaces, and external feedback, so causal attribution is limited. Code competence also creates execution risks and does not guarantee reliable planning under partial observability.

### Relevance to the survey

Use as evidence that agent backbones benefit from jointly learned language and code capabilities. For web agents, the result supports executable actions, but also shows that backbone improvements alone do not solve interaction reliability.
