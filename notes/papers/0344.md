#### Thesis-ready paragraph

WorkArena: How Capable Are Web Agents at Solving Common Knowledge Work Tasks? extends the benchmark landscape for LLM-based web agents by focusing on **enterprise browser benchmark / browsergym origin**. Its central contribution is that it evaluates agent behavior under conditions that are underrepresented in the core S5.1 P0 benchmarks. Specifically, it introduces or analyzes the setting: **33 ServiceNow-based knowledge-worker tasks in the final ICML version.**. This matters for the thesis because generalized web automation and structured data extraction cannot be evaluated only by a single success score or by a single environment type. A robust web agent must generalize across websites, handle dynamic or multimodal content, maintain long-horizon context, avoid unsafe actions, and produce verifiable outputs. The paper's main finding is that **Shows a significant gap between current agents and reliable automation of common knowledge-work tasks.**. However, its limitation is equally important: **Restricted to ServiceNow-style enterprise workflows; not directly about open-web browsing or extraction.**. Therefore, the paper should be used as a P1 support reference that sharpens the S5.1 benchmark taxonomy and motivates later technical sections on grounding, planning, training, failure modes, safety, and deployment.

#### Concrete evidence verified from the full paper

- **Environment:** WorkArena evaluates agents inside a real enterprise platform (ServiceNow) rather than a toy webpage simulator.
- **Atomic benchmark:** it defines **33 task types** and generates **19,912 valid task instances** with programmatic evaluators.
- **Result gap:** the best GPT-4 configuration reports about **42.7% success**; a Llama-3-70B configuration is about **17.9%**.
- **Evaluation:** tasks are checked against the resulting application state, which is stronger evidence of correct completion than trajectory matching.
- **Failure modes:** enterprise forms, tables, navigation hierarchy and exact state manipulation expose grounding and procedural weaknesses.

##### Author-stated / evidence-based limitations

WorkArena is tied to one enterprise platform and its schemas/workflows. Programmatic state checks establish whether a task was completed but do not by themselves measure safety, cost or whether an alternative path was unnecessarily risky.
