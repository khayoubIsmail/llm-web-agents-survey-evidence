#### Thesis-ready paragraph

OSWorld: Benchmarking Multimodal Agents for Open-Ended Tasks in Real Computer Environments extends the benchmark landscape for LLM-based web agents by focusing on **general computer-use benchmark with web/desktop apps**. Its central contribution is that it evaluates agent behavior under conditions that are underrepresented in the core S5.1 P0 benchmarks. Specifically, it introduces or analyzes the setting: **369 computer tasks across operating systems, real web and desktop apps, file I/O, and multi-app workflows.**. This matters for the thesis because generalized web automation and structured data extraction cannot be evaluated only by a single success score or by a single environment type. A robust web agent must generalize across websites, handle dynamic or multimodal content, maintain long-horizon context, avoid unsafe actions, and produce verifiable outputs. The paper's main finding is that **Humans reach over 72% while best models reach around 12%, indicating severe GUI grounding and operational-knowledge gaps.**. However, its limitation is equally important: **Broader than web agents; web automation is one part of a general computer-use benchmark.**. Therefore, the paper should be used as a P1 support reference that sharpens the S5.1 benchmark taxonomy and motivates later technical sections on grounding, planning, training, failure modes, safety, and deployment.

#### Concrete evidence verified from the full paper

- **Benchmark:** OSWorld contains **369 real-computer tasks on Ubuntu** plus **43 Windows tasks** used in analysis, spanning multiple applications and cross-application workflows.
- **Evaluation:** the environment implements **134 state-based evaluation functions**, allowing task outcomes to be checked in the operating system/application state.
- **Human-agent gap:** humans achieve about **72.36%**, while the best evaluated model in the original study reaches only **12.24%**; the workflow-guided baseline is about **6.57%**.
- **Failure analysis:** high-resolution visual grounding, repetitive low-level actions, application-specific operational knowledge and long-horizon error recovery are major bottlenecks.
- **Importance:** OSWorld shows that computer-use competence remains far below humans even when frontier multimodal models can reason about screenshots.

##### Author-stated / evidence-based limitations

The benchmark is expensive to run and sensitive to OS/application versions. It samples a finite set of desktop workflows and does not directly measure Web-data provenance or schema-complete extraction.
