AndroidWorld is a dynamic Android benchmark for autonomous agents. It evaluates whether agents can interact with real or realistic Android apps through observations and actions.

#### Concrete evidence verified from the full paper

- **Environment:** AndroidWorld defines **116 tasks across 20 real Android applications**.
- **Dynamic generation:** task parameters are randomly instantiated, producing millions of possible variants rather than a fixed test list.
- **Durable evaluation:** every task supplies initialization, success checking and teardown logic that inspects actual device state.
- **Result:** the strongest original agent completes **30.6%** of tasks.
- **Robustness:** small task variations significantly change performance, showing that a single fixed phrasing/state can overestimate practical reliability.
- **Transfer:** adapting a desktop-Web agent to mobile is less effective, arguing against assuming cross-platform universality.

##### Author-stated / evidence-based limitations

Results depend on Android/app versions and emulator behavior; 20 apps cannot cover the full mobile ecosystem. Programmatic completion checks do not capture every usability or safety concern.

---

#### Limitations

- **Limitation 1:** Android UI automation differs from desktop/web automation.
- **Limitation 2:** Dynamic apps create non-determinism and reproducibility challenges.
- **Limitation 3:** Task success depends on the agent’s perception/action interface.

General limitation for your thesis:

```text
A benchmark evaluates only a slice of agent behavior.
No single benchmark proves that an agent can perform generalized web automation and data extraction.
```

Therefore, use this paper as a **P2 supporting source**, not as the sole basis for a central claim.
