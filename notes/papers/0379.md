#### Concrete evidence verified from the full paper

- **Benchmark:** Spider2-V contains **494 real-world data-science/engineering tasks across 20 enterprise applications**.
- **Action diversity:** tasks combine code/SQL generation with fine-grained GUI operations in live executable computer environments.
- **Result:** the strongest original GPT-4V agent reaches only about **14.0% overall success**.
- **Guidance does not solve grounding:** verbose step-by-step instructions raise GPT-4o to only about **16.2%** on the verbose subset, while tasks requiring remote accounts/workspaces remain around **10.6%**.
- **Failure implication:** domain knowledge plus correct code is insufficient when agents cannot reliably manipulate professional GUIs and cloud state.

##### Author-stated / evidence-based limitations

Enterprise software credentials and cloud services complicate reproducibility, and application versions change. The benchmark is intentionally data-workflow-specific rather than a general Web sample.

---

#### Limitations

- **Limitation 1:** Results may be environment-specific.
- **Limitation 2:** Office/workplace tasks often require exact state changes that are hard for agents to verify.
- **Limitation 3:** Live or high-fidelity environments increase realism but also evaluation complexity.
