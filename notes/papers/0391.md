#### Concrete evidence verified from the full paper

- **Fresh benchmark:** the initial paper release uses **1,319 tasks from 93 repositories** created from GitHub issues since 2024; the final NeurIPS dataset grew to **1,890 tasks across 223 repositories**.
- **Reproducible execution:** each issue task has a dedicated Docker environment and tests, enabling patch correctness to be executed rather than judged textually.
- **Automation:** an automated curation/build pipeline removes much of the manual bottleneck that prevented frequent benchmark refreshes.
- **Finding:** agent/model performance drops substantially on fresh live tasks compared with static SWE-bench variants, consistent with contamination/overfitting concerns.
- **Analysis:** the paper separately examines repository origin, issue recency and task difficulty to explain the static/live gap.

##### Author-stated / evidence-based limitations

Continuous updates mean benchmark versions must be pinned for reproducible comparisons. Automated environment construction can fail on unusual repositories, and software issue resolution is adjacent rather than identical to browser automation.
