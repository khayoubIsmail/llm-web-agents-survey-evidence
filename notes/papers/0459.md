---

#### Concrete evidence verified from the full paper

Dual-View contextualizes each candidate HTML element with nearby elements in both the DOM/text view and rendered screenshot view, exploiting the tendency of related controls to be spatially grouped. Evaluated on Mind2Web, the method consistently improves the baseline in cross-task, cross-website and cross-domain settings. The result isolates local multimodal context as a useful signal for choosing the correct web action.

##### Author-stated / evidence-based limitations

The method still assumes access to aligned HTML elements and screenshots and is evaluated primarily as action selection on Mind2Web. It does not remove the need for planning, recovery or safe online execution.

---

#### Limitations

- **Limitation 1:** Visual contextualization can be expensive.
- **Limitation 2:** The approach depends on accurate element localization and page rendering.
- **Limitation 3:** It supports navigation but does not fully solve long-horizon recovery or verification.

General thesis-level limitation:

```text
Better perception or representation is necessary but not sufficient.
A generalized web agent also needs planning, memory, action execution, error recovery, and evaluation.
```

Therefore, this paper should be used as **P2 support** for S5.2, not as the only foundation for the whole section.
