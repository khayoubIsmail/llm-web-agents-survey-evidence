## Analysis

<!-- note-body-start -->
### Research problem and contribution

OSCAR is a generalist desktop/mobile agent that translates natural-language tasks into executable Python for mouse and keyboard control. It models execution as a state machine, using GUI-grounded observations, explicit error handling, and task-driven replanning when live state diverges from expectations.

### Method and evaluation

The planner generates code around standardized controls; state checks determine whether to continue, recover, or replan. Experiments use GAIA (466 tasks across three complexity levels), OSWorld (369 tasks), and AndroidWorld (116 tasks across 20 applications), plus static GUI analyses. OSCAR reports 28.7% average success on GAIA and 13.5% on its hardest level, 24.5% on OSWorld, and 61.6% on AndroidWorld. Ablations reduce performance to roughly 70% and 80% of the full system when GUI grounding or task-driven replanning is removed.

### Limitations and critical assessment

Absolute desktop success remains low, and executing generated Python creates security and sandboxing requirements. Results use particular proprietary multimodal backbones and benchmark snapshots; OS/application updates can invalidate actions. State-machine structure improves recoverability but cannot ensure the visual state was interpreted correctly.

### Relevance to the survey

OSCAR is directly relevant to state-aware web/GUI control. It provides concrete evidence for executable plans plus replanning, while its low absolute success cautions against equating code generation with reliable automation.
