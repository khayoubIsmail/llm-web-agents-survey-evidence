---

#### Concrete evidence verified from the full paper

R2D2 combines Remember and Reflect. Remember stores a replay buffer that reconstructs a map of previously visited web states; Reflect analyzes failed behavior and revises strategy. On WebArena the paper reports a 50% reduction in navigation errors and roughly a threefold increase in task completion relative to the compared baseline. The result supports explicit episodic navigation memory plus failure reflection rather than relying only on the LLM context window.

##### Author-stated / evidence-based limitations

A replay buffer can retain stale or misleading states when websites change, and reflection quality depends on correctly identifying the cause of failure. Memory growth and retrieval also create additional overhead.

---

#### Limitations

- **Limitation 1:** Memory quality depends on what is stored, summarized, and retrieved.
- **Limitation 2:** Bad or stale memories can mislead the agent.
- **Limitation 3:** Memory mechanisms add complexity and can increase cost.

General thesis-level limitation:

```text
Better planning does not automatically mean generalized web automation is solved.
The agent still needs perception, grounding, execution, verification, recovery, and safety.
```

Therefore, this paper should be used as **P2 support**, not as the only foundation for S5.3.
