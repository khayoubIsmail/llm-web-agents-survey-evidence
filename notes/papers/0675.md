#### Concrete evidence verified from the full paper

OneKE is explicitly schema-guided: a Schema Agent analyzes predefined or induced schemas, an Extraction Agent runs the selected LLM/extraction method, and a Reflection Agent debugs erroneous cases using a configurable knowledge base. The system handles raw Web HTML and PDF input and supports NER, relation, event, triple and open-domain extraction. The paper evaluates on two NER/RE benchmarks and demonstrates web-news and PDF-book case studies without requiring task-specific fine-tuning. This is direct system-level evidence that schema configuration, extraction and post-hoc correction can be separated into collaborating agents.

##### Author-stated / evidence-based limitations

As a WWW demonstration paper, the empirical section is compact and does not establish large-scale live-web robustness, field-level provenance or cross-site scraper generalization. The Reflection Agent can correct known error patterns but does not guarantee independent factual verification.
