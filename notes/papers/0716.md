#### Concrete evidence verified from the full paper

HackWorld evaluates computer-use agents on realistic vulnerable web applications through graphical interaction. It contains 36 applications spanning 11 frameworks and seven programming languages, with vulnerabilities placed in realistic dynamic interfaces and scored through a CTF-style objective. Frontier CUAs achieve exploitation rates below 12%; qualitative analysis finds weak cybersecurity awareness, poor multi-step attack planning and incorrect use of available security tools. The result is useful as capability-risk evidence: present agents can interact with vulnerable software but remain weak autonomous exploiters.

##### Author-stated / evidence-based limitations

The benchmark is intentionally curated and cannot represent the full space of real vulnerabilities or defensive controls. Low exploitation rates reflect both security-policy behavior and capability failures, so they should not be interpreted as a robust safety guarantee.
