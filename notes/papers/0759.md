#### Concrete evidence verified from the full paper

MINJA shows that an attacker can poison an agent's long-term memory using only ordinary query/output interaction, without direct database access. Bridging reasoning steps and progressive shortening make malicious records both injectable and retrievable for later victim queries. Experiments report injection success above 95% across tested agents/datasets and attack success above 70% on most datasets, while benign utility drops stay below 2% overall on MIMIC-III, eICU and WebShop. This makes memory-writing interfaces a practical integrity boundary.

##### Author-stated / evidence-based limitations

The attack assumes the agent stores attacker interactions into reusable memory and that retrieval is similarity driven. Strong provenance, write authorization or memory isolation can invalidate that assumption.
