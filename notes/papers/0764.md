#### Concrete evidence verified from the full paper

VeriSafe Agent translates a user's mobile instruction into a formal DSL specification and checks each proposed GUI action against that specification before execution. Evaluation covers 300 user instructions across 18 popular mobile apps. VSA verifies actions with 94.3%-98.33% accuracy, a 20.4%-25.6% improvement over LLM-only verification methods, and increases the underlying GUI agent's task-completion rate by 90%-130% by preventing/correcting invalid actions.

##### Author-stated / evidence-based limitations

Safety depends on correctly autoformalizing user intent; an incorrect specification can deterministically enforce the wrong behavior. Coverage is limited to the DSL and mobile-app action semantics.
