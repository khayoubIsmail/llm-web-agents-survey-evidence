#### Concrete evidence verified from the full paper

This review expands the agent threat model from prompt injection to failures in plugins, connectors, structured tool calls and inter-agent protocols. It emphasizes that ad-hoc authentication, inconsistent schemas and weak validation create attack surfaces even when the base LLM is well aligned, and organizes mitigations around authentication/authorization, input-output validation, least privilege, isolation, monitoring and protocol-aware controls. It is useful synthesis evidence that security must cover the full agent workflow rather than only prompts.

##### Author-stated / evidence-based limitations

The paper is a review, not a controlled benchmark, and protocol ecosystems such as MCP are changing quickly. Its threat categories therefore need continual updating.
