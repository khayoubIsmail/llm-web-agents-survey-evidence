#### Concrete evidence verified from the full paper

The study first evaluates 20 LLM agents across 16 core dimensions on three representative CVEs, then selects OpenHands, SWE-agent and CAI for an 80-CVE end-to-end benchmark spanning six web technologies and seven vulnerability types. Agents perform reasonably on simpler library-based vulnerabilities but consistently struggle with service-based vulnerabilities requiring multi-component setup and authentication. Authentication is a major bottleneck: OpenHands with Claude-Sonnet-4 reaches 67% trigger success with a manually supplied token, 50% when the agent must log in, and 8% with no authentication information; across configurations, autonomous login causes about a 33.3% average degradation. The paper concludes that executing exploit code is not equivalent to successfully reproducing a vulnerability in its real environment.

##### Author-stated / evidence-based limitations

The 80-CVE benchmark is much more realistic than isolated CTF/code tasks but still covers a bounded set of technologies and vulnerability classes. Results are sensitive to provided setup/authentication guidance, and real-world reproduction can involve credentials, infrastructure and external dependencies outside the benchmark.
