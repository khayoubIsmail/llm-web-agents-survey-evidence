#### Concrete evidence verified from the full paper

ADAM treats persistent agent memory as a queryable privacy surface and iteratively adapts extraction queries using an estimated data distribution and entropy-guided active selection. Experiments across three agent/dataset settings, four LLMs, four attack baselines and four defenses show substantial improvements over prior memory-extraction attacks, with attack-success rates reaching up to 100% in tested configurations. The paper also finds that larger memories expose more retrievable surface area and that ordinary rate limiting is not a robust defense: low-concurrency adaptive querying can continue extracting information while avoiding many bans. The result motivates provenance, access control and privacy defenses at the memory layer rather than only input filtering.

##### Author-stated / evidence-based limitations

The threat model assumes repeated query access to an agent whose retrieval/memory behavior exposes information correlated with stored records. Exact extraction effectiveness depends on memory architecture, data distribution and model responses, so the reported maximum ASR should not be generalized to every agent-memory implementation.
